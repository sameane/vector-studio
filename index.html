دليل دمج Vector Studio مع التطبيقات الخارجية (postMessage API)

يمكنك تضمين محرر Vector Studio بسهولة داخل أي تطبيق ويب (React, Vue, Angular, Laravel, PHP, WordPress) عبر وسم <iframe>، وتبادل الصور وبيانات الـ SVG والتصدير الحي بكل سلاسة عبر بروتوكول window.postMessage ثنائي الاتجاه.

1️⃣ إرسال البيانات من تطبيقك إلى Vector Studio (الأوامر الواردة):

أرسل رسالة إلى الـ iframe عبر iframe.contentWindow.postMessage(message, targetOrigin). استخدم أصل التطبيق الفعلي بدلاً من * متى أمكن:

  • IMPORT_IMAGE: لإدراج صورة عادية (Base64 أو URL):
    { type: 'IMPORT_IMAGE', data: { url: 'https://example.com/logo.png' } }
  • IMPORT_SVG: لاستبدال مساحة العمل بكود SVG متجهي كامل:
    { type: 'IMPORT_SVG', data: { svgString: '<svg>...</svg>' } }
  • REQUEST_EXPORT: لطلب تصدير التصميم الحالي وإعادته لتطبيقك. format هي png أو svg؛ scale يحدد دقة PNG (من 1 إلى 4)، وcloseOnExport اختياري لإرسال طلب إغلاق بعد نتيجة التصدير:
    { type: 'REQUEST_EXPORT', data: { format: 'png', scale: 2, closeOnExport: true } }
  • SET_ARTBOARD: لتعديل قياسات اللوحة ولونها برمجياً:
    { type: 'SET_ARTBOARD', data: { width: 1200, height: 630, background: '#ffffff' } }
  • CLEAR_CANVAS: لمسح جميع العناصر من اللوحة:
    { type: 'CLEAR_CANVAS' }

2️⃣ استقبال النتائج في تطبيقك (الأحداث الصادرة):

استمع للأحداث الصادرة من الاستوديو عبر window.addEventListener('message', callback). كل رسالة تحتوي type وpayload وtimestamp؛ افحص event.source وevent.origin قبل الوثوق بالمرسل.

  • VECTOR_STUDIO_READY: يُرسل تلقائياً فور اكتمال تحميل المحرر لتبدأ بإرسال البيانات.
  • VECTOR_STUDIO_EXPORT_RESULT: نتيجة التصدير. يحوي payload.format وقياسات الصورة؛ ويحتوي payload.svgString لصيغة SVG أو payload.dataUrl لصيغة PNG:
    { type: 'VECTOR_STUDIO_EXPORT_RESULT', payload: { format: 'png', dataUrl: 'data:image/png;base64,...', width: 1600, height: 1200 } }
  • VECTOR_STUDIO_CLOSE: يصدر بعد نتيجة التصدير عند استخدام زر «إلى التطبيق الأب» أو إرسال closeOnExport: true. على التطبيق الأب إخفاء/إزالة الـ iframe؛ لا يستطيع iframe إغلاق الصفحة الحاضنة.
  • VECTOR_STUDIO_EXPORT_ERROR: فشل التصدير؛ يحوي payload.format وpayload.message.
  • VECTOR_STUDIO_CHANGE: تعديل في اللوحة؛ يحوي payload.layerCount.

3️⃣ نموذج كود جاهز للتطبيق الأب (Parent App Integration Code):

// 1. تضمين المحرر
const iframe = document.querySelector('#vectorStudioIframe');
const targetOrigin = 'https://your-site.com';

// 2. استقبال النتائج والأحداث من المحرر
window.addEventListener('message', (event) => {
  if (event.source !== iframe.contentWindow) return;
  if (event.origin !== targetOrigin) return;
  const { type, payload } = event.data || {};

  if (type === 'VECTOR_STUDIO_READY') {
    // أصبح المحرر جاهزاً؛ مثال إرسال صورة إلى اللوحة
    iframe.contentWindow.postMessage({
      type: 'IMPORT_IMAGE',
      data: { url: 'https://your-site.com/avatar.png' }
    }, targetOrigin);
  }

  if (type === 'VECTOR_STUDIO_EXPORT_RESULT') {
    // PNG: payload.dataUrl — SVG: payload.svgString
    console.log('تم استلام:', payload.format, payload);
  }

  if (type === 'VECTOR_STUDIO_CLOSE') {
    iframe.hidden = true; // أو أغلق النافذة/أزل الـ iframe
  }

  if (type === 'VECTOR_STUDIO_EXPORT_ERROR') {
    console.error('فشل التصدير:', payload.message);
  }
});

// 3. طلب PNG ثم إغلاق واجهة المحرر بعد إرسال النتيجة
function exportPngAndCloseStudio() {
  iframe.contentWindow.postMessage({
    type: 'REQUEST_EXPORT',
    data: { format: 'png', scale: 2, closeOnExport: true }
  }, targetOrigin);
}
